🔄 DATA FLOW
────────────

Initial Load:
  Browser → Load index.html
           → GA4 init script runs in <head>
           → React loads
           → GoogleAnalytics component mounts
           → gtag('js', new Date()) + gtag('config', GA_MEASUREMENT_ID)
           → GA4 script loads async
           → First page_view event sent

Navigation (/blog):
  User clicks link
  → React Router updates location
  → useLocation() hook detects change
  → trackPageView('/blog') called
  → gtag('event', 'page_view', {page_path: '/blog', ...})
  → Sent to Google Analytics

Form Submission:
  User fills form → Clicks "שלחי פרטים"
  → Validation passes
  → submitLead() API call
  → Response success
  → trackLead() [Meta Pixel]
  → trackGenerateLead() [Google Analytics]
  → Both systems notified simultaneously
